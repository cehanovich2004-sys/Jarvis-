# JARVIS Plans

## Current Status

The project is in Phase 0 plus the first vertical slice of Phase 1.

Internal implementation may reach `READY FOR CTO REVIEW`, but only the external CTO may mark the phase `APPROVED`.

## Phase 0

- Establish repository instructions.
- Establish project-scoped Codex agents.
- Create TypeScript project skeleton.
- Document security boundaries and architecture decisions.

## Phase 1 First Vertical Slice

- Local TypeScript core.
- Loopback-only HTTP API.
- CLI command for asking the local core.
- Typed contracts.
- Input validation.
- Unit and integration tests.
- In-memory repository documented as a replaceable limitation.

## Phase 2 Candidate Scope

Do not begin this phase without external CTO approval.

Potential candidates:

- Persistent storage decision.
- Expanded command taxonomy.
- Authentication or local capability gating if local network or native clients are introduced.
- Apple client design spike after CTO approval.
- Real Codex integration design only after explicit security review.
